═══════════════════════ 2. ЗАМЫСЕЛ (ОРАКУЛ) ═══════════════════════

Задуманное поведение (сверь с кодом и комментариями; расхождение кода с этим
списком — находка; противоречие внутри списка — тоже назови):
- Настройки: auto_hide_roles_enabled (прятать при входе в игру, CSS на все
  роли); role_phase_auto_switch_enabled (днём прятать, ночью показывать
  автоматически — через ~3 с после начала ночи); автосцены OBS (obs-panel:
  своя роль пином днём скрыта, ночью показана ТОЛЬКО когда эфир на ночной
  сцене); hotkey_role_hide (D по умолчанию, переназначаемый); hotkey_role_peek
  (V по умолчанию); подмена роли F/E (role-faker).
- D: переворачивает видимость ВСЕХ ролей стола разом. Исключение по замыслу:
  днём при автосценах OBS свою роль D не показывает (пин) — только V.
- V (удержание): пока держишь — видны все роли; отпустил — РОВНО как было до
  нажатия. Исключение: ночной показ «положен» (автосмена, ночь, игрок после
  наступления ночи роли руками не трогал) И эфир на ночной сцене — тогда
  остаются видны. Потеря фокуса (alt-tab, сворачивание) = отпускание. Пустое
  нажатие (скрывать нечего) отдаётся сайту.
- Ручное действие игрока этой ночью (D, пункт меню, Ctrl/Cmd+D) ночная
  автоматика не переигрывает до следующей ночи.
- Эфир НЕ на ночной сцене при автосценах OBS (заранее — до команды дневной
  сцены; ушёл с ночной руками; разрыв OBS) — прячутся ВСЕ роли (своя —
  пином, сокомандники — CSS), независимо от автосмены фаз; вернулся —
  показ, если положен, иначе снимается только сценовое скрытие. Уведомление
  «Игрок является …» прячется вместе с ролями.
- F (подмена): своя роль показывает фальшивку, чужие роли скрыты; D во время
  подмены не действует (тост); E возвращает всё. F меняет СОДЕРЖИМОЕ своей
  роли и не показывает скрытые роли; под подменой V не показывает
  сокомандников (подмена главнее — иначе обман раскрыт в эфире).
- Ничего не меняется само: ожидание, перерисовка узла сайтом, реконнект,
  смена вкладки — без изменений видимого.
- Принятые ограничения (НЕ находки, но попробуй показать, что они хуже, чем
  заявлено): пока у игрока зажата посторонняя клавиша, сайт не принимает D —
  ночной показ может не случиться (роли скрыты, не в эфир); Ctrl/Cmd+D у
  игрока БЕЗ опции модификатора — закладка браузера, но засчитывается как
  ручное действие; автоскрытие без автосмены прячет только при входе.
